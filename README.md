# RE4 DLSS patch notes

Patch notes for RE4 DLSS, an REFramework plugin that adds NVIDIA DLSS, DLSS Frame Generation and Reflex to
Resident Evil 4 (2023). The notes are in [index.md](index.md) and published with GitHub Pages.

Download the mod on [Nexus Mods](https://www.nexusmods.com/residentevil42023/mods/7795).
